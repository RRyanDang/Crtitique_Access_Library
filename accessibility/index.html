Accessibility of This Site

A report about access should be reachable itself. These are the choices behind this site.

Structure and navigation

  • A skip to main content link is the first thing a keyboard or screen reader user reaches on every page.
  • Each page uses one h1 and a heading order with no skipped levels, so the page can be navigated by headings.
  • Landmarks (header, nav, main, footer) are marked up semantically.
  • There are no dropdown menus. Hover menus are hard to use with a keyboard, a touchscreen or a magnifier, so sections have landing pages instead.
  • Every page links to the next one, and the footer carries a full site map.

Text and colour

  • Body text is 18px with a line height of 1.65 and a maximum line length of about 70 characters.
  • Text is near-black on white, a contrast ratio of about 17:1. The blue used for links and banners meets WCAG AA.
  • Links are underlined as well as coloured, so colour is never the only signal.
  • The layout is responsive and works at 200% zoom without horizontal scrolling.

Images and video

  • Images that carry meaning have descriptive alt text. Decorative images use an empty alt attribute so screen readers skip them.
  • Every image also has a visible caption and a source line.
  • Videos are linked rather than embedded, so no autoplaying third-party player is forced on the reader. All three have captions available on YouTube.

No JavaScript

The site is plain HTML and CSS. Nothing here depends on scripting, so nothing breaks when scripting fails or is blocked.

Known limitation

This site has not been tested with a screen reader by a screen reader user. Following the argument of this report, that testing is the part that should not be left to the person who built it.
